# Meta-Ads-Performance-ROI-Optimization-Dashboard

---

##  Overview

This project analyzes Meta Ads (Facebook & Instagram) performance to understand user engagement, campaign effectiveness, and conversion efficiency.

The goal is to enable data-driven decisions that help optimize ad spend and improve return on investment (ROI).

---

##  Tools Used

* Power BI
* Power Query (Data Transformation)
* DAX (Data Analysis Expressions)

---

##  Data Preparation

Data preparation was performed using Power Query:

* Cleaned and formatted dataset
* Handled missing and inconsistent values
* Standardized column formats
* Created calculated columns and date structure

---

##  Data Modeling

* Built relationships between tables
* Designed a structured data model for efficient analysis

---

##  Key DAX Measures

* CTR (Click Through Rate)
* Engagement Rate
* Conversion Rate
* Purchase Rate
* Dynamic metric selection using slicer

---

##  Dashboard Features

* KPI cards for performance overview
* Platform filter (Facebook vs Instagram)
* Dynamic measure selection
* Time-based analysis (hourly & daily trends)
* Country-wise performance analysis
* Age group segmentation
* Ad type performance comparison

---

##  Key Insights

* Facebook outperforms Instagram in engagement and conversions
* Peak engagement observed between 8 AM – 12 PM
* Weekend performance is stronger than weekdays
* USA contributes the highest engagement
* Carousel and Image ads perform better than other formats

---

##  Business Recommendations

* Allocate more budget to Facebook campaigns
* Optimize Instagram targeting and creatives
* Run ads during peak engagement hours
* Focus on high-performing audience segments
